## 1. Введение и постановка задачи

**Цель проекта:** Предсказать стоимость авиабилета на основе характеристик рейса — авиакомпании, маршрута, класса обслуживания, времени вылета, количества пересадок и глубины покупки.

**Практическая ценность:** Модель помогает пассажирам выбрать оптимальное время покупки билета, а авиакомпаниям — анализировать ценообразование конкурентов.

**Формулировка задачи:** Регрессия — предсказание числового значения цены в рупиях.

**Обоснование метрики качества:**  
- **RMSE** (Root Mean Squared Error) — основная метрика. Штрафует за большие ошибки сильнее чем MAE, что важно при предсказании цен: ошибка на 10 000 рупий гораздо хуже чем на 1 000.  
- **MAE** — дополнительная метрика. Интерпретируется как средняя абсолютная ошибка в рупиях.  
- **R²** — показывает долю объяснённой дисперсии, удобен для общей оценки качества модели.

## 2. Поиск и описание данных

**Источник:** [Flight Price Prediction — Kaggle](https://www.kaggle.com/datasets/shubhambathwal/flight-price-prediction)

Датасет выбран потому что содержит реальные данные о рейсах индийских авиакомпаний, имеет достаточный объём и разнообразие признаков для полноценной ML-задачи регрессии.

**Описание датасета:**
- **Объём:** 300 153 строк, 11 колонок
- **Тип задачи:** Регрессия (таргет — `price`)

| Признак | Тип | Описание |
|---|---|---|
| airline | categorical | Авиакомпания (6 уникальных) |
| flight | categorical | Код рейса |
| source_city | categorical | Город отправления (6 городов) |
| departure_time | categorical | Время суток вылета |
| stops | categorical | Количество пересадок (zero/one/two_or_more) |
| arrival_time | categorical | Время суток прилёта |
| destination_city | categorical | Город назначения |
| class | categorical | Класс обслуживания (Economy/Business) |
| duration | numeric | Длительность полёта (часы) |
| days_left | numeric | Дней до вылета на момент покупки |
| **price** | **numeric** | **ТАРГЕТ: цена билета (рупии)** |

## 3. Обработка и подготовка данных

**Полная очистка:**
- **Пропуски:** отсутствуют (df.isnull().sum() = 0)
- **Дубликаты:** не обнаружены
- **Выбросы:** удалены значения вне 1–99 перцентиля по цене (< 1% данных)
- **Типы данных:** категориальные признаки закодированы (OrdinalEncoder для порядковых, LabelEncoder для номинальных)

**Feature Engineering — создано 7 новых признаков:**

| Признак | Описание |
|---|---|
| route | Комбинация source + destination |
| is_direct | Бинарный: рейс без пересадок |
| is_business | Бинарный: бизнес-класс |
| is_last_minute | Бинарный: покупка за ≤7 дней |
| booking_category | Категория заблаговременности (4 класса) |
| duration_minutes | Длительность в минутах |
| is_long_flight | Бинарный: длиннее медианы |

Итого признаков: 16 (9 исходных + 7 новых).

**Ключевые визуализации:**
- Распределение цены: правостороннее, логарифм сглаживает
- Класс — самый сильный предиктор (Business в 3–5× дороже Economy)
- Чем меньше дней до вылета — тем дороже (особенно < 20 дней)

**Сплит данных:**
- Train: 70% (210 107 строк)
- Val: 15% (45 023 строки)
- Test: 15% (45 023 строки)
- Случайный сплит корректен: данные не временной ряд, собраны в один момент времени → data leakage невозможен.

## 4. Baseline-модель

**Модель:** Linear Regression без feature engineering, только исходные 9 признаков.

**Результаты:**

| Модель | Val RMSE | Val MAE | Val R² |
|---|---|---|---|
| DummyRegressor (mean) | 21 927 | 19 132 | 0.000 |
| **Linear Regression (baseline)** | **6 319** | **4 276** | **0.917** |

Linear Regression уже показывает R²=0.917, но не может уловить нелинейные зависимости (например нелинейное влияние класса и дней до вылета).

## 5. Эксперименты

### Таблица экспериментов

| Модель | Гипотеза | Метод | Val RMSE | Val R² | Вывод |
|---|---|---|---|---|---|
| KNN (k=10) | Похожие рейсы → похожая цена | KNeighborsRegressor | ~8 500 | ~0.85 | Хуже линейной |
| Ridge + FE | FE улучшит линейную модель | Ridge, все признаки | ~6 100 | ~0.92 | Незначительное улучшение |
| Random Forest | Деревья лучше улавливают нелинейности | RF, 100 деревьев | ~2 800 | ~0.98 | Значительный прирост |
| XGBoost | Бустинг превзойдёт RF | XGB, n=300, lr=0.1 | ~2 100 | ~0.99 | Лучше RF |
| LightGBM | LightGBM быстрее и точнее XGBoost | LGBM, n=300, lr=0.1 | ~2 050 | ~0.99 | Лучший базовый |
| XGBoost + log(price) | log-трансформация уменьшит ошибку | log1p → expm1 | ~2 200 | ~0.98 | Не улучшает |
| **LightGBM + Optuna** | **Подбор гиперпараметров улучшит LGBM** | **50 trials TPE** | **~1 900** | **~0.99** | **Лучшая модель** |
| Ансамбль RF+XGB+LGB | Усреднение снизит дисперсию | VotingRegressor | ~2 000 | ~0.99 | Не превзошёл LGBM |

**Перебор гиперпараметров (Optuna):**
- `n_estimators`: 100–500
- `learning_rate`: 0.01–0.3
- `max_depth`: 3–10
- `num_leaves`: 20–150
- `subsample`, `colsample_bytree`: 0.6–1.0

## 6. Финальная модель и интерпретируемость

**Выбор финальной модели:** LightGBM с гиперпараметрами подобранными через Optuna.

**Обоснование:**
- Лучший Val RMSE среди всех моделей
- Быстро обучается на больших данных
- Хорошо работает с категориальными признаками без One-Hot Encoding
- Ансамбль не дал прироста — модель уже достаточно мощная

**Важность признаков (Feature Importance):**

Топ признаки по влиянию на цену:
1. `class_encoded` — Business vs Economy (наибольшее влияние)
2. `days_left` — глубина покупки
3. `airline_encoded` — авиакомпания
4. `duration` — длительность полёта
5. `stops_encoded` — количество пересадок

**Интерпретация:**
- Бизнес-класс увеличивает цену в 3–5 раз
- Покупка за < 20 дней значительно дороже
- Vistara и Air India — самые дорогие авиакомпании
- Более длинные рейсы дороже, но нелинейно

## 7. Деплой

**API:** FastAPI (`app/main.py`)
- `GET /` — информация об API
- `GET /health` — проверка состояния
- `POST /predict` — предсказание цены

Пример запроса:
```bash
curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "airline": "Vistara",
    "source_city": "Delhi",
    "destination_city": "Mumbai",
    "departure_time": "Morning",
    "arrival_time": "Afternoon",
    "stops": "zero",
    "flight_class": "Economy",
    "duration": 2.17,
    "days_left": 30
  }'
```

Пример ответа:
```json
{
  "predicted_price": 5823.50,
  "currency": "INR",
  "model": "LightGBM (Optuna)"
}
```

**Интерфейс:** Streamlit (`app/streamlit_app.py`)
- Выбор авиакомпании, маршрута, класса, времени вылета
- Слайдеры для длительности и дней до вылета
- Кнопка предсказания → отображение цены

**Запуск локально:**
```bash
# Терминал 1 — API
uvicorn app.main:app --reload

# Терминал 2 — UI
streamlit run app/streamlit_app.py
```

**Запуск через Docker:**
```bash
docker-compose up --build
```

## 8. Заключение и выводы

**Итоги:**
- Лучшая модель LightGBM + Optuna достигла Val RMSE ≈ 1 900 рупий (R² ≈ 0.99)
- Это в 11.5 раз лучше baseline (RMSE 21 927 у DummyRegressor)
- Ключевые факторы цены: класс обслуживания, дней до вылета, авиакомпания

**Ограничения:**
- Датасет содержит только индийские авиакомпании и маршруты внутри Индии
- Данные собраны в один период — модель может не учитывать сезонность
- Нет данных о конкретных датах вылета

**Возможные улучшения:**
- Добавить признаки сезонности (месяц, день недели, праздники)
- Попробовать нейросетевые подходы (TabNet, CatBoost)
- Собрать данные за несколько лет для учёта трендов
- Добавить данные о загруженности маршрута
